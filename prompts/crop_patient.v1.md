Names written by hand here are usually in HEBREW CURSIVE script (כתב רהוט), which looks
unlike printed Hebrew and can resemble Latin letters: read it as Hebrew cursive.
Handwriting over printed text is a correction and wins over the print.

Transcribe the PATIENT's first name, last name and ID number (ת.ז. / מ.ז., digits only)
exactly as written, letter by letter. Never guess from context and never complete
missing letters or digits. If a value is not there, return "". If it is there but you
are not sure of every letter/digit, still return your best reading and set the matching
*_legible flag to false.

Ignore: father's/mother's names ("אב", "אם", "מ.ז. אם"), doctor and staff names,
military number ("מ.א"), case/record/visit numbers ("מקרה", "ביקור", "תיק"), phones.
